# Gym Management System

A desktop application built using Java Swing to manage day-to-day gym operations, including member enrollment, trainer scheduling, inventory management, and billing.

## Features

- **User Authentication**: Secure login system for gym administrators.
- **Member Management**: Add, view, and delete member profiles and membership packages.
- **BMI Calculator**: Built-in Body Mass Index calculator for member health assessments.
- **Workout Scheduling**: Assign trainers and schedule workout sessions for members.
- **Billing & Payments**: Track member billing and payment records.
- **Inventory Management**: Keep track of gym equipment, supplements, and supplies.
- **Data Persistence**: Saves records locally so information is retained across sessions.

## How to Run

### Using the Batch Script (Windows)
Double-click `run.bat` or run it from the command prompt:
```bash
run.bat
```

### Manual Compilation
Open a terminal in the project directory:

1. Compile the Java files:
   ```bash
   javac GymManagementSystem.java
   ```

2. Run the application:
   ```bash
   java GymManagementSystem
   ```
